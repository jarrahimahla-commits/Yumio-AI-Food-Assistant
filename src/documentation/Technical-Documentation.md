مستند فنی پروژه Yumio

دستیار هوشمند پیشنهاد غذا و آشپزی در تلگرام

AI-Powered Telegram Cooking Assistant

۱. معرفی پروژه

Yumio یک ربات تلگرامی مبتنی بر هوش مصنوعی است که با دریافت مواد غذایی موجود در خانه، به کاربران برای انتخاب غذا و آشپزی کمک می‌کند. این ربات با استفاده از هوش مصنوعی Cloudflare Workers AI، پیشنهادهای غذایی متناسب با درخواست کاربر ارائه می‌دهد.

۲. اهداف پروژه

* ساده‌تر کردن انتخاب غذا
* پیشنهاد غذا بر اساس مواد اولیه موجود
* کاهش زمان تصمیم‌گیری برای آشپزی
* ارائه دستور پخت غذاها
* توجه به سلیقه و محدودیت‌های غذایی کاربران

۳. قابلیت‌های سیستم

* شروع کار با دستور /start
* نمایش راهنمای استفاده با دستور /help
* دریافت مواد غذایی از کاربر
* پیشنهاد سه غذای متناسب با مواد اولیه
* ارائه زمان تقریبی پخت و مواد لازم
* توضیح مراحل تهیه غذا
* پاسخ‌گویی به زبان فارسی

۴. فناوری‌های استفاده‌شده

* Telegram Bot API: ارتباط ربات با کاربران
* Cloudflare Workers: اجرای کد ربات در فضای ابری
* Cloudflare Workers AI: پردازش درخواست‌ها با هوش مصنوعی
* JavaScript: زبان برنامه‌نویسی پروژه
* Webhook: دریافت خودکار پیام‌های تلگرام

۵. معماری سیستم

سیستم از سه بخش اصلی تشکیل شده است:

۱. کاربر پیام خود را در تلگرام ارسال می‌کند.

۲. تلگرام پیام را از طریق Webhook به Cloudflare Worker ارسال می‌کند.

۳. Worker درخواست را به مدل هوش مصنوعی می‌فرستد و پاسخ تولیدشده را با استفاده از Telegram Bot API به کاربر برمی‌گرداند.

۶. مراحل پیاده‌سازی

مرحله اول: ساخت ربات تلگرام

با استفاده از BotFather یک ربات جدید ساخته شد و توکن اختصاصی دریافت گردید.

مرحله دوم: ایجاد Cloudflare Worker

یک Worker برای اجرای برنامه JavaScript ایجاد شد.

مرحله سوم: اتصال هوش مصنوعی

قابلیت Workers AI فعال شد و مدل زیر برای تولید پاسخ‌ها مورد استفاده قرار گرفت:

@cf/meta/llama-3.1-8b-instruct-fast

مرحله چهارم: تنظیم توکن

توکن ربات به‌عنوان Secret با نام TELEGRAM_BOT_TOKEN در تنظیمات Cloudflare ذخیره شد.

مرحله پنجم: تنظیم Webhook

آدرس Worker به تلگرام معرفی شد تا پیام‌های کاربران به‌صورت خودکار دریافت شوند.

۷. نحوه عملکرد کد

کد اصلی پروژه در فایل src/worker.js قرار دارد.

بخش‌های اصلی برنامه عبارت‌اند از:

* بررسی نوع درخواست ورودی
* دریافت اطلاعات پیام تلگرام
* استخراج شناسه کاربر و متن پیام
* ارسال پیام به تلگرام با تابع sendMessage
* پردازش دستورات /start و /help
* نمایش وضعیت تایپ کردن با sendChatAction
* ارسال درخواست به مدل هوش مصنوعی با env.AI.run
* دریافت پاسخ و ارسال آن به کاربر
* مدیریت خطاها با try/catch

۸. مفاهیم رایانش ابری در پروژه

رایانش بدون سرور (Serverless): اجرای برنامه بدون نیاز به مدیریت مستقیم سرور.

هوش مصنوعی ابری: استفاده از مدل هوش مصنوعی از طریق زیرساخت Cloudflare.

API: ارتباط بین سرویس‌های مختلف نرم‌افزاری.

Webhook: ارسال خودکار اطلاعات از تلگرام به Worker هنگام دریافت پیام جدید.

Secret Management: نگهداری امن اطلاعات محرمانه مانند توکن ربات.

۹. آزمایش و ارزیابی

برای بررسی عملکرد سیستم، موارد زیر آزمایش شدند:

* شروع ربات با دستور /start
* نمایش راهنما با دستور /help
* ارسال فهرست مواد غذایی
* دریافت پیشنهادهای غذایی
* درخواست دستور پخت
* بررسی پاسخ‌گویی هوش مصنوعی

۱۰. مزایای پروژه

* استفاده آسان از طریق تلگرام
* عدم نیاز به نصب نرم‌افزار جداگانه
* استفاده از زیرساخت ابری
* پاسخ‌گویی هوشمند به درخواست کاربران
* امکان توسعه و افزودن قابلیت‌های جدید

۱۱. محدودیت‌های پروژه

* عدم ذخیره تاریخچه مکالمات کاربران
* نداشتن پایگاه داده اختصاصی
* وابستگی به سرویس‌های تلگرام و Cloudflare
* امکان خطا یا نادرستی در پیشنهادهای هوش مصنوعی
* عدم اعتبارسنجی تخصصی ارزش غذایی و حساسیت‌ها

۱۲. قابلیت‌های قابل توسعه

در نسخه‌های آینده می‌توان امکانات زیر را اضافه کرد:

* ذخیره اطلاعات و تاریخچه کاربران
* استفاده از پایگاه داده D1
* شخصی‌سازی پیشنهادها بر اساس سلیقه کاربر
* افزودن دسته‌بندی غذاهای ایرانی و خارجی
* ارائه برنامه غذایی روزانه
* پشتیبانی از ارسال تصویر مواد غذایی

۱۳. نتیجه‌گیری

پروژه Yumio نمونه‌ای از کاربرد هوش مصنوعی و رایانش ابری در زندگی روزمره است. این سیستم با ترکیب Telegram Bot API و Cloudflare Workers AI می‌تواند در انتخاب غذا و یادگیری دستور پخت به کاربران کمک کند. همچنین ساختار ساده و ابری آن امکان توسعه قابلیت‌های بیشتر را در آینده فراهم می‌کند.
